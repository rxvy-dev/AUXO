Setting up the VM

  1. Graphics controller VMSVGA, 128 MB video memory, 3D acceleration off.
  2. Boot the ISO and install as normal.
  3. When the install finishes and the VM restarts, the ISO's boot menu appears again. Choose Boot existing OS, or remove the ISO from the VM's virtual drive before restarting.

What's inside

The parts of an Arch install people do by hand.

Bootable snapshots

Every update takes a btrfs snapshot. Boot an older one from GRUB, then keep it with auxo-rollback.

GPU detected at install

RTX cards get nvidia-open with modesetting. AMD and Intel get Vulkan and video acceleration.

Safe dual boot

os-prober on, install alongside Windows or another Linux, existing EFI partition reused.

Works offline

No connection still gets you Plasma and the stable kernel. You're told what was skipped.

zram swap

Compressed RAM swap with tuned settings instead of a swap partition.

Ready for games and code

multilib on. Steam, Lutris, MangoHud, compilers, SDL2/SDL3 and Docker are one checkbox away.
