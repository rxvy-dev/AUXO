Climb your own setup.

Auxo is Arch Linux with a graphical installer and a set of tools you can keep using after install. Pick your desktop, accent colour, kernel and shell when you install. Change any of them later without reinstalling.

The installer

Five choices, one guided installer.

Auxo uses Calamares with its own pages for each choice below. Partitioning handles dual boot by detecting other systems and reusing your existing EFI partition. With no internet, you still get a complete Plasma desktop.

What's inside

The parts of an Arch install people usually do by hand.

Bootable snapshots

Btrfs with snapper and snap-pac takes a snapshot on every pacman run. If an update breaks something, boot an older snapshot from GRUB, then run auxo-rollback to keep it.

GPU detected at install

NVIDIA RTX cards get nvidia-open with modesetting. On zen and lts kernels it switches to the DKMS build automatically. AMD and Intel get Vulkan and video acceleration. Unused drivers are removed.

Safe dual boot

os-prober is on, and Calamares can install alongside Windows or another Linux. The live menu includes NVIDIA and safe-graphics entries.

Offline-aware

With no connection the installer finishes with Plasma and the stable kernel. It tells you which choices were skipped and the one command that adds them later.

zram, not a swap partition

Compressed RAM swap with tuned sysctls, set up automatically.

Ready for games and code

multilib is enabled. Steam, Lutris, MangoHud and Prism Launcher are one checkbox, and so are compilers, SDL2/SDL3 and Docker.

After install

Change it later without reinstalling.

The installer runs these same commands, so installing and changing things later give the same result.

auxo-tweak

An interactive menu, or one command per change. Desktops, kernels, drivers, mirrors, zram, services and the paru AUR helper.

auxo-tweak accent rose
auxo-tweak desktop hyprland   # riced, SDDM set
auxo-tweak kernel linux-zen
auxo-tweak snapshots on

auxo-update

Shows Arch news since your last update, takes a snapshot, updates repo packages, AUR and Flatpak, then flags .pacnew files, orphans and whether you need to reboot.

auxo-update
▲ Snapshot before update
▲ Repository packages
▲ Health check  — all good

auxo-rollback

Choose a snapshot and it becomes your system again on the next boot. /home is never touched, and the old system is kept until you delete it.

auxo-rollback          # pick from a list
auxo-rollback 42       # or by number

auxo-fetch

A fast system summary drawn in your accent colour. Includes --json for scripts and --small for your shell greeting.

auxo-fetch --small
   ●   you@auxo · Auxo Linux
  /\   6.16-zen · Hyprland

Desktops

Three rices, four classic desktops.

The Hyprland, Sway and i3 setups come with a bar, launcher, notifications, lock screen and screenshots already wired up. Your old dotfiles are kept as *.auxo-bak.

Build it yourself

On any Arch system. Other distros can use scripts/build-in-docker.sh.

git clone https://github.com/auxolinux/auxo
cd auxo
sudo ./build.sh
./scripts/test-vm.sh out/auxo-linux-*.iso
