Auxo 3 was based on Arch Linux and used the Calamares installer. It's no longer developed: there won't be new Auxo 3 images or updates to its Auxo tools. Systems you install from it still get Arch package updates through pacman. For new installs, use Auxo 4.

03 Step three

Make a bootable USB stick

Pick the computer you're using right now.

  1. Download Rufus, Ventoy or balenaEtcher and plug in a USB stick (8 GB or larger). Everything on it will be erased.
  2. In Rufus, select the Auxo image and click Start. When asked, choose Write in DD Image mode. With Ventoy, install Ventoy to the stick and copy the image onto it.
  3. Restart, open the boot menu (usually F12, F11, F8 or Esc) and choose the USB stick. If Windows is using Fast Startup, shut down fully first.
  1. Download balenaEtcher, choose the Auxo image and your USB stick, then click Flash. Or use the Terminal:
  2. Find the stick, unmount it and write the image (replace diskN with your stick):
    $ diskutil list $ diskutil unmountDisk /dev/diskN $ sudo dd if=auxo-linux-2026.10.05-x86_64.iso of=/dev/rdiskN bs=4m
  3. Intel Macs: hold Option at startup and pick the USB stick. Apple Silicon Macs can't boot Auxo, because it's built for x86_64.
  1. Use Fedora Media Writer, GNOME Disks (Restore Disk Image) or Ventoy, or write it with dd:
  2. Find your USB stick and write the image (replace sdX with your stick, not a partition):
    $ lsblk $ sudo dd if=auxo-linux-2026.10.05-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync
  3. Reboot, open your boot menu and choose the USB stick.

03 Or, for a VM

Set up your virtual machine

Settings that work in each app. Skip this if you're installing on a PC.

  1. New VM: type Linux, version Other Linux (64-bit). Give it at least 4 GB RAM, 2 CPUs and a 25 GB disk. Tick Enable EFI if you want a UEFI install.
  2. Settings → Display: graphics controller VMSVGA, video memory 128 MB, 3D acceleration off.
  3. Attach the Auxo image as the optical drive, start the VM and install as normal.
  4. When the installer says Auxo is installed, power off, remove the image from the optical drive, and start the VM again.
  1. With virt-manager: create a VM from the image, choose Generic Linux as the OS, 4 GB RAM and a 25 GB disk. Video: Virtio.
  2. Or from a terminal:
    $ qemu-img create -f qcow2 auxo.qcow2 25G $ qemu-system-x86_64 -enable-kvm -cpu host -smp 2 -m 4G \ -drive file=auxo.qcow2,if=virtio -cdrom auxo-linux-2026.10.05-x86_64.iso \ -boot d -vga virtio
  3. After installing, start it again without -cdrom and -boot d.
  1. New VM: guest OS Linux, version Other Linux 6.x kernel 64-bit. 4 GB RAM, 2 CPUs, 25 GB disk.
  2. Point the CD/DVD drive at the Auxo image and install as normal.
  3. After installing, disconnect the CD/DVD drive and restart.
Using a VM? Remove the image from the virtual drive after installing, or the VM boots the live session again.

04 Step four

Verify and install

Check the download, boot it, and start the installer from the welcome app.

Install Auxo

Boot the USB stick or VM, then:

  1. Choose Auxo Linux in the boot menu. The live KDE Plasma desktop starts.
  2. Click Install Auxo Linux in the welcome app, or run sudo auxo-installer in a terminal. For Wi-Fi, press N on the installer's first page.
  3. Use the arrow keys, type to search, Enter to pick and Esc to go back. Choose your keyboard, language, time zone and disk: erase a disk, or use partitions you made to dual boot.
  4. Choose your desktop, accent colour, kernel and shell, create your account, and tick any extras.
  5. Check the summary and press Install. Nothing on your disk changes before this step.
  6. When it says Auxo is installed, restart and remove the USB stick.

Verify your download

Make sure the image downloaded completely before you write it. Compare the result with the SHA-1 on the file's Checksums page.

# Linux $ sha1sum auxo-linux-2026.10.05-x86_64.iso # macOS $ shasum -a 1 auxo-linux-2026.10.05-x86_64.iso # Windows (PowerShell) > Get-FileHash auxo-linux-2026.10.05-x86_64.iso -Algorithm SHA1

A mismatch means the download was cut off or corrupted. Download it again, or use the torrent.

Releases

Release notes and older versions

Auxo is a rolling release: once installed, auxo-update keeps you current. You don't need to reinstall for new versions.

What's new in 4.0

Auxo moves from Arch Linux to Void Linux.

  • NewBuilt on Void Linux, with runit and xbps instead of systemd and pacman
  • NewA fast, keyboard-driven text installer with a review screen, for UEFI and BIOS, erase or dual boot
  • Newauxo-tweak nvidia picks the right NVIDIA driver; scheduler, power, firewall, dns and cleanup commands
  • NewKernels: Void's linux, linux-lts and linux-mainline
  • NewSnapshots before every auxo-update and every hour, bootable from GRUB
  • ChangedNo boot splash: Auxo boots straight to the login screen
