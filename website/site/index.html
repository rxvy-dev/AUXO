01 Why Auxo

Arch, without the weekend of setup

Everything you'd normally configure by hand after installing Arch, done during install and still yours to change.

Ready in minutes

A guided installer sets up your desktop, drivers, snapshots and dual boot in one go.

Still pure Arch

Official Arch repositories, pacman, the AUR and the Arch Wiki all work as normal.

Change anything later

auxo-tweak swaps your desktop, kernel, shell or accent colour without reinstalling.

Undo bad updates

Every pacman transaction takes a btrfs snapshot you can boot from GRUB and roll back to.

03 How it works

Install once. Change anything. Undo mistakes.

Three tools cover the whole life of your system. Full command reference →

1

Install

A guided installer. Pick your desktop, accent, kernel, shell and extra software, and Auxo sets up drivers, snapshots and dual boot. We recommend linux-zen and zsh.

# in the live session
❯ auxo-welcome
✓ Install Auxo Linux
2

Change anything

auxo-tweak runs the same code as the installer, so a change later gives the same result as a fresh install.

❯ auxo-tweak desktop hyprland
❯ auxo-tweak kernel linux-zen
❯ auxo-tweak accent
3

Undo mistakes

Snapshots are taken before and after every pacman run. Boot one from GRUB, then make it permanent.

❯ auxo-update
:: news · snapshot · repo · AUR · Flatpak
❯ auxo-rollback --list
