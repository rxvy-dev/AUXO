03 How it works

Install once. Change anything. Undo mistakes.

Three tools cover the whole life of your system. Full command reference →

1

Install

A keyboard-driven text installer. Pick your desktop, accent, kernel, shell and extras. It shows you a summary and changes nothing until you press Install.

# in the live session
❯ sudo auxo-installer
✓ Auxo is installed
2

Change anything

auxo-tweak runs the same commands as the installer, so a change later gives the same result as a fresh install.

❯ auxo-tweak desktop hyprland
❯ auxo-tweak kernel linux-lts
❯ auxo-tweak accent
3

Undo mistakes

A snapshot is taken before every update. Boot one from GRUB, then make it permanent.

❯ auxo-update
:: snapshot · xbps · flatpak
❯ auxo-rollback --list

04 Extras

The extras, one checkbox away

These are the installer's real Extras. Tick what you want during setup, or turn any of them on later with auxo-tweak. Everything else is an xbps-install away.

Snapshots

Bootable btrfs snapshots before every update, with snapper and grub-btrfs.

on by default

zram swap

Compressed swap in RAM, so the system stays responsive when memory is tight.

on by default

GPU drivers

The right driver for your NVIDIA, AMD or Intel graphics.

on by default

Firewall

ufw, set to block incoming connections and allow outgoing.

optional

Flatpak

Flatpak with Flathub, for apps that aren't in Void's repositories.

optional · needs internet

Gaming

Steam, GameMode, MangoHud and gamescope, with Void's nonfree and multilib repos.

optional · needs internet
